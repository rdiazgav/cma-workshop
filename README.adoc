= Custom Metrics Autoscaler on OpenShift Local

This workshop walks through four progressive steps of configuring the Custom Metrics Autoscaler (CMA) on a single OpenShift Local (CRC) cluster. You start with a Spring Boot application running at a fixed replica count, then add CPU-based autoscaling, Prometheus-based autoscaling via thanos-querier, and cron-based scaling with a pause annotation.

== View the Course

The full course is published at: https://<github-user>.github.io/cma-workshop

== Local Development

To preview the course site locally:

[source,bash]
----
npm install
npm run dev
----

This starts a live-reload server at http://localhost:3000.

== Build the Site

[source,bash]
----
npx antora site.yml
----

The generated site is output to `gh-pages/`.

== Repository Structure

[cols="2,4",options="header"]
|===
| Directory | Purpose

| `documentation/`
| Antora courseware source (AsciiDoc pages, navigation, attributes)

| `00-setup/`
| Namespace manifest

| `01-baseline/`
| Deployment, Service, and Route for the demo app with fixed replicas

| `02-cpu-trigger/`
| ScaledObject with CPU trigger and load-generating Job

| `03-prometheus-trigger/`
| ServiceAccount, ClusterRoleBinding, TriggerAuthentication, ServiceMonitor, and ScaledObject with Prometheus trigger

| `04-cron-trigger/`
| ScaledObject with cron trigger and pause annotation example
|===
